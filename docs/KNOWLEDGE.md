# 认知自动整理

## 设计

定期合并重复认知，仅在有明确更正或状态变化依据时更新旧结论；时间较新本身不代表更可信，无法判断的矛盾保留双方说法并标记“待确认”。聊天指令、引用和玩笑不能直接当作事实。

人工固定内容优先，包含固定空值。个人按分类保护；已经人工维护的群摘要及群认知整体固定。自动整理不改写原始依据，不发送群通知，不改变权限，不取消跨会话公开审核。

默认开启，每个整理单元成功处理后至少间隔一天，有新增或变化才再次请求模型。首次启动可整理已有资料。失败保留原内容，人工修改或依据变化后不采用过期结果。

认知仍按 QQ 关联和存储。正式回复、参与判断及历史查询结果发送给模型前，文字中的已知个人账号与群号统一按当前平台昵称与群名呈现；结构化账号、消息编号和工具参数保留原值。名称没有同步时保留原号。不自动附加账号与名称对应表；模型需要数字编号时主动按完整名称查询，同名返回多个候选，不自动选定。机器人自身账号与当前昵称明确标记为“机器人自己”，不能混同主人或当前发言人。

认知提取、自动整理及后台生成存储方案继续使用原始账号和依据，防止昵称变化影响资料归属与原文核验。

## 开发

- `plugins/assistant/consolidation.py` 负责筛选、输出校验、依据指纹、失效判断及原子写入；接入 `Assistant.refresh_profiles` 后台循环，每轮最多四个单元，失败至少一小时后重试。
- 个人按机器人、会话、用户、分类读取 `facts`，不修改原表。含人工修正或本人管理指令标记的分类跳过；单分类两至二百条时整理，超限保留原认知。
- 群按机器人及群号隔离，读取最近一百二十条非机器人发言，每条向模型提供最多六百字，形成近期摘要和群背景，不从私聊提取群资料。
- `LLM.consolidate_knowledge` 使用当前模型、超时与并发限制，不提供工具；提示词为 `llm.knowledge_cleanup.0`。严格校验个人文本、群摘要及群认知的输出结构和长度。
- `data/knowledge-cleanup.json` 保存派生结果、时间、依据指纹及群来源快照，是含聊天内容的本机私有缓存。写入前重新核验依据与群固定状态，通过同目录临时文件原子替换。
- 个人回复先执行原有来源公开审核，再匹配指纹；可见依据不完整时退回原始可见认知。后台 `person_value` 显示整理内容，证据仍为原始记录。
- `group_knowledge` 统一读取群内容，人工配置始终优先，包括空值。来源删除或修改时自动结果失效，新增消息等待下轮整理。后台仅修改活跃度等设置不固定自动认知，编辑摘要或认知后则整体固定。
- 成功、失败和来源数量记入现有日志，模型上下文沿用日志开关，不记录模型内部思维。

- `plugins/assistant/names.py` 共用当前平台目录 `data/contacts.json`；在每个回答或参与判断请求内建立昵称映射，每轮工具交互从原始消息生成独立展示副本。文本与嵌入 JSON 分开处理，保留结构化数字、链接、图片地址、工具调用与推理数据。消息编号引用优先整体识别，避免数字昵称或账号匹配破坏编号；纯数字昵称不从普通数字片段推断。兼容旧认知中的裸编号、方括号、QQ号、群号和带字段前缀的文字引用；人物与群恰好同号时，裸数字不猜测归属。身份补充仅标记机器人自己，不附加名称目录。
- `identity_context` 明确提供 `bot_self`；`LLM.reply`、`LLM.investigate`、`LLM.plan_participation` 统一投影文字，后台请求预览沿用同一路径。昵称和群名片均无权限意义。
- 后台资源保留原始 `value`，另返回 `display_value`、`display_evidence` 与带人物/群类型的 `display_parts`；昵称展示不进入认知版本计算，不写回数据库。建议差异也使用当前昵称展示，保存仍提交原始内容。前端通过文本节点渲染高亮片段，昵称不作为 HTML 执行。

- `HistoryTools.run` 支持 `resolve_user` 与 `resolve_group`，通过 `query` 精确匹配名称或编号，通过 `scope` 限定已获准会话；仅返回匹配结果，每页最多十项。同名返回 `ambiguous`，未知返回 `not_found`，空查询不允许列出全目录。查询不会扩大原有会话权限。

## 使用说明

后台设置可调整开关及间隔，也可在 `.env` 设置：

```dotenv
KNOWLEDGE_CLEANUP_ENABLED=true
KNOWLEDGE_CLEANUP_INTERVAL_HOURS=24
```

间隔一至七百二十小时，配置修改后重启机器人。关闭开关停止新整理，已有有效结果仍可读取。

后台个人与群页面可查看结果，编辑保存即可按上述范围固定。“待确认”矛盾可人工修正，模型判断不等于事实核实。群自动结果覆盖近期聊天，不保证包含完整群史。

原始认知、人工固定内容与聊天记录沿用私有迁移；派生缓存不纳入迁移，目标机器重新生成。停机后可删除缓存强制重新整理，不会删除原始记录；缓存含聊天资料，不应公开上传。

没有变化、未到间隔、已人工固定、个人分类不足两条或超过二百条时不会请求模型。失败检查日志中的 `knowledge_cleanup` 与模型请求记录，默认至少一小时后重试。整理使用实际模型额度，候选较多时分轮处理。

个人与群认知默认按当前昵称阅读，点击“编辑原文”维护以 QQ 记录的文字，保存后恢复昵称视图。无需迁移旧认知；昵称目录更新后重新载入页面，新模型请求也会使用新昵称。未替换的账号请先检查平台目录是否已同步；机器人标记来自实际登录账号。

旧认知无需重新请求模型或重写数据库，加载时即适用新显示规则。后台人物昵称为蓝色文字、群名为紫色文字，不使用背景高亮；展开“编辑原文”仍可查看数字编号。模型可自主查询昵称对应 QQ、群名对应群号，未查询时不附加对应表。
