# 后台设置

## 设计

设置页供本机维护者调整模型和运行限制、默认参与积极性与人设，并管理扩展插件。配置由维护者直接保存，不向模型开放修改权限。密钥只允许填写替换，留空保持不变，浏览器不读取原值。保存校验参数及读取版本，并在本机保留原值备份。

默认积极性用于未单独设置的群；默认人设用于没有单独选择人设的群及私聊。群管理提供本群积极性滑块和插件开关。全局关闭优先于群开关，群绑定插件不能跨群开启。

积极性为零时普通群消息不主动参与，直接 @机器人仍可处理；原生“@全体成员”也会以较高关注度进入判断，但不保证回复。全体提醒临时提高本条消息的关注值，不修改滑块或持久配置，具体规则见 [群聊与表情处理](CHAT.md)。

扩展插件可以批量卸载其配置、定时任务和运行数据，核心功能不可卸载。卸载须先停止机器人，避免执行中的插件写回。原文件保留本机备份；历史开发任务与报告作为操作历史保留。

## 开发

`console_settings.py` 维护可编辑字段白名单，提供 `.env`、默认设置及插件管理服务；`admin_server.py` 暴露 `/api/settings`、`/api/defaults`、`/api/plugins`、`/api/plugins/switch` 和 `/api/plugins/delete`，沿用本机访问与令牌校验。设置和插件不属于模型建议资源。

`.env` 通过临时文件原子替换，保留其他字段和注释，原文件备份到 `backups/settings/`。响应只含白名单运行字段与密钥是否已配置，不含密钥值。运行中的机器人持有启动时配置，因此保存后需重启；后台后续模型请求重新读取配置。

`group_chat.json` 保存 `default_activity` 和 `default_persona`，按请求读取。已有群配置优先，未覆盖的群跟随默认值；只修改群认知不会将继承中的积极性固定为群覆盖。默认人设的文件受到删除保护，迁移模板重命名同时更新默认引用。

`LLM_THINKING_ENABLED` 控制模型请求：DeepSeek 的 `thinking.type` 使用 enabled 或 disabled；OpenAI 开启时发送 `reasoning.effort=high`，关闭时对推理系列发送 none，普通非推理型号不附加该参数。型号必须支持对应参数，不自动更换型号。依据为 [DeepSeek 思考模式](https://api-docs.deepseek.com/guides/thinking_mode/) 和 [OpenAI 推理说明](https://developers.openai.com/api/docs/guides/reasoning)。思考内容不展示给用户。

插件状态沿用 `data/plugins.json`，快照写入检查文件版本并使用独立锁，防止后台开关被运行中旧快照覆盖。`data/plugin-controls.json` 是本机瞬时开关时间，用于使旧定时确认失效并跳过关闭期间的计划，不纳入迁移。卸载持有机器人运行锁与迁移锁，删除安装记录并将生成插件目录移到 `backups/plugins/`。随仓库提供的定时扩展源码保留，删除安装记录后不运行；核心模块不在卸载列表中。

## 使用说明

1. 在“设置”调整默认积极性滑块（0—100）及默认人设，点击“保存默认设置”，后续请求生效。
2. 运行配置按模型、上下文、请求限制、搜索和图片分组；修改后点击“保存运行配置”。密钥输入框始终为空，填写新值才替换，保存成功清空输入框。
3. 重启机器人使运行配置生效。深度思考只控制是否启用，不显示思考过程；OpenAI 所选型号须支持 high / none 档位。
4. 全局插件管理可直接开启、关闭扩展插件。勾选多个插件后点击批量卸载，核对确认信息；机器人运行时卸载会被拒绝，停止机器人后重试。
5. “群管理”中调整本群积极性并保存；本群插件开关单独即时保存，全局关闭时本群开启仍不会运行。

发生版本冲突时刷新数据后重新修改。参数无效时不会保存；不支持的模型参数会在请求时报服务错误。运行配置、默认设置及插件的原文件分别位于 `backups/settings/` 和 `backups/plugins/`，这些备份不在资源“操作记录”中，恢复时应停止机器人并人工核对版本。备份包含原密钥与插件数据，沿用私有备份管理方式。

验证使用隔离数据和模拟服务，覆盖密钥不回显、参数范围、版本冲突、默认继承、群隔离、停机卸载和两家服务的思考开关请求。
