# 人格与说话方式模板

## 设计

人格描述角色身份、性格、兴趣、相处分寸与真实感边界；说话方式描述措辞、篇幅、节奏、格式与示例。两者可以独立搭配，同名组合提供完整的角色体验。

| 配套名称 | 人格特点 | 说话方式 |
| --- | --- | --- |
| 损友 | 爱接梗、嘴欠但知道收手，不拿隐私和痛处开玩笑 | 短促吐槽、反问、轻轻拆台，正事正常回答 |
| 小鲸鱼 | 蓝白鲸鱼娘同人形象，傲娇、嘴硬心软 | 短碎口语、偶尔怪话与角色梗 |
| 猫娘 | 轻快、有脾气的二次元猫娘，不接受恋爱或占有设定 | 每次文字回复自然带喵，正事收敛撒娇 |
| 技术宅 | 爱聊自建服务和硬件，重视依据与排查前提 | 先结论或方向，再给依据，命令保持完整 |

角色形象不代表模型厂商、现实身体或真实经历。小鲸鱼不喜欢“大肥鱼”称呼；默认人格仍保留自己原有的称呼偏好，两者分别选择。昵称不决定人格。

所有模板服从项目统一的真实性、权限、隐私、工具和参与规则。模板不配置发送、拍一拍、记忆或权限机制，不强制每条消息都参与。明确求助不受闲聊短句限制，不以玩梗代替核查。

## 开发

- 人格文件：`personas/损友.txt`、`personas/小鲸鱼.txt`、`personas/猫娘.txt`、`personas/技术宅.txt`。
- 风格文件：`styles/损友.txt`、`styles/小鲸鱼.txt`、`styles/猫娘.txt`、`styles/技术宅.txt`。
- 文件使用 UTF-8 编码和 CRLF 行尾，每份正文不超过 4000 字符。
- `plugins/assistant/personality.py` 的 `ProfileStore` 枚举同目录下非默认的 `.txt` 文件，按文件名提供可选项。每次请求重新读取选中的内容，不需要新增注册代码。
- `plugins/assistant/prompts.py` 把人格与风格作为 JSON 偏好注入统一提示词；群设置分别保存两种选择，不自动联动。
- 示例只用于展示口吻，不能视为共同经历或固定答案。发送格式、工具及能力说明由项目统一提示词负责。

## 使用说明

在目标群由具有权限的群管理员、群主或机器人所有者执行：

```text
/人格 列表
/风格 列表
/人格 切换 猫娘
/风格 切换 猫娘
```

把“猫娘”替换成表格中的其他名称即可。两项分别切换；只换人格不会自动改说话方式。猫娘的每轮带喵规则在风格中，想完整体验应同时选择。

也可在本机后台的提示词管理查看、维护模板，并在群设定中选择。文件新增后列表可读取，后续请求使用最新内容，无需重启。新增模板不会自动修改当前群选择或默认模板。

恢复默认分别执行 `/人格 默认`、`/风格 默认`。私人对话沿用项目默认配置，不通过上述群指令切换。

验证时先查看列表，再检查后台完整请求组装预览中的人格和风格；用普通招呼、角色身份问题及明确求助各测一次。猫娘检查喵是否自然，损友检查说“别闹”后是否收住，小鲸鱼检查角色形象与实际模型身份是否分开，技术宅检查不确定性和命令格式。

选项不存在时检查文件目录、扩展名和名称；读取失败时检查 UTF-8 编码、空内容及 4000 字符限制。实际生成具有随机性，模板读取通过不代表每次回复都严格符合口吻。
