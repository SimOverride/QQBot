# 表情收藏与搜索图片

## 设计

收藏偏好由使用当前人设的聊天模型决定；安全审核只检查隐私、色情、严重血腥等限制，不以审美、人设、通用性或是否属于表情包拒绝图片。安全通过不代表必须收藏或发送。

优先考虑同群十分钟内至少两位群友复读的表情，以及与当前人设形象、兴趣、表达习惯相关的表情。复读提示不绕过安全限制，不强制收藏；同一人重复发送、引用和机器人自己的图片不增加独立人数。

为辅助解释，允许发送搜索到的安全图片，无须先进入表情包库，也不自动收藏。收藏和发言独立，保持沉默时仍可收藏；一次回复与本地表情合计最多一张图片。私聊图片不进入群收藏候选，网络查询不得携带私密资料。

## 开发

- `vision.py` 的 `Vision.observe` 接收去重后的群消息，按机器人账号、群号及平台图片标识记录最近发图者。优先使用文件中的哈希；否则使用图片地址，移除临时鉴权参数但保留图片身份参数。缓存最多两千张图片，不持久化，不下载所有群图片做比较；无法匹配平台标识的同图可能漏识别。
- `Vision.prepare` 在实际图片输入旁加入复读标记。收藏及参与判断由带当前人设的模型完成；程序不硬编码角色关键词或自动保存复读图片。
- `emote_collect.py` 管理本轮候选与下载字节。`inspect_emote_image`、`inspect_image` 共用安全审核；已有内容描述不是安全凭据，也需要审核。
- `search_images` 复用图片搜索服务；`choose_image` 仅接受本轮搜索所得且已检查、已通过安全审核的候选。工具只选择待发送字节，不即时发送，不接受模型自拟网址或本地路径。
- `llm.py` 将选中图片交给 `service.py`；群和私聊发送入口使用字节构造平台图片消息，复用过期回复检查和发送失败处理。成功后仅记录图片占位说明，不把图片字节或临时下载地址写入聊天正文。
- 下载复用 `image_download.py` 的公网地址检查、重定向校验、DNS 固定、超时和大小限制，并校验支持的图片文件头。域名全部解析为 `198.18.0.0/15` 代理虚拟地址时，通过固定的 Cloudflare HTTPS DNS 入口 `https://1.1.1.1/dns-query` 重新解析，验证全部结果为公网地址后固定连接；不允许直接访问虚拟 IP，不放行内网或混合私网结果，每次跳转重新校验。
- 图片搜索与网页搜索共用请求次数；收藏与直发共用每轮最多四次下载尝试、两次安全审核。下载失败不占用安全审核次数，失败原因返回模型并进入工具结果日志；收藏仍受原有每天及图库容量限制。
- `llm.review_emote_image.0` 管理安全审核，`llm.investigate.0` 管理收藏偏好，`llm.images.0` 管理解释配图；均可在后台查看。安全审核不包含当前人设，收藏决策包含当前人设。

## 使用说明

配置 `SEARCH_API_KEY` 后即可搜索图片；搜索直发不依赖 `EMOTES_AUTO_COLLECT`，关闭自动收藏仍可配图解释。图片大小沿用 `EMOTES_MAX_BYTES`。更新代码后重启机器人生效，后台提示词修改对后续请求生效。

本机代理采用 Fake-IP 时需能访问上述 HTTPS DNS 入口；解析失败会明确返回下载错误，不能跳过公网校验或安全审核发送。普通公网 DNS 不调用该入口。

可让机器人“找张结构图解释一下”，也可由模型判断配图是否有帮助。无需要求先收藏。群内自然复读会提供收藏优先提示，但活跃度为零时仍仅处理显式触发，不额外主动回复。

验证时分别检查复读人数、群隔离、超时失效、人设相关收藏，以及关闭收藏后的搜索直发。未配置搜索、下载失败、安全不通过、检查次数耗尽或发送失败时不能宣称发图成功。模型判断不是绝对保证，维护者仍可检查与清理图库。

当前消息的留档图片可作为收藏候选，读取本地字节后仍执行原有安全审核。聊天原图独立归档、历史按需查看及迁移说明见 [聊天图片](CHAT_IMAGES.md)。
