# 插件体系

## 设计

将非基础通信功能封装为独立扩展，统一管理功能注册、可用范围、全局与群开关、权限和数据。QQ连接、身份识别、群角色核验、普通聊天和已有扩展功能仍由现有模块负责。内置独立插件为定时消息，另支持本机自主任务生成并发布的群限定插件，参见[本机自主任务](TASKS.md)。

全局开关按机器人账号隔离，仅机器人主人可修改；群开关仅当前群的群主、群管理员和机器人主人可修改。全局关闭优先于群开启。未配置的群默认关闭。群限定插件只能在预先指定的账号与群号范围内使用，管理命令不能扩大范围；改群名不影响绑定。私聊不能操作群插件，但机器人主人可在私聊管理本账号全局开关。

模型可调用的插件工具必须根据当前群实际状态提供，执行时再次核验开关及平台权限。群聊自主参与判断和未被明确呼叫的主动回复不提供定时管理工具。当前插件所有操作需要管理员身份，创建和取消由原发起人确认后生效。

内置插件是随项目审核的可信本地代码，与机器人在同一进程运行。自动生成插件通过独立进程测试及调用，不导入机器人主进程；这不是操作系统安全沙箱，仍须只批准可信开发需求。生成插件测试通过后自动发布到原群。

## 开发

`plugins/extensions/manager.py` 提供 `Manager` 和绑定当前账号、群、发言者、角色查询回调的 `Session`。插件声明 `id`、`title`、`command_name`、`functions`，实现 `execute(session, args)`、`command(session, args)`、`tick(manager, bots, now)`。注册在机器人启动入口完成，首个实例为 `Schedule()`。新增可信插件还须补充其数据校验和迁移规则，不能仅增加工具描述。

`plugins/extensions/store.py` 原子读写 `data/plugins.json`，按 `bots → 账号 → 插件 → data → 群号` 隔离数据；`enabled` 为全局开关，`scope` 为限定群号列表，`groups` 保存各群开关。`scope=null` 可用于通用插件，群限定插件使用明确列表。聊天中的插件管理接口不修改 `scope`。配置损坏时停止提供插件能力，普通聊天仍可运行。

`Commands` 分派插件命令，确认及开关结果原样发送，不经模型改写。`Assistant` 只为显式群请求绑定插件会话；`LLM.investigate` 动态装配插件工具并交由对应插件执行。工具执行复用现有工具轮次上限与诊断日志。

机器人启动创建每两秒一次的插件维护任务，关闭时取消并等待退出。定时插件的停用维护仅推进错过的任务状态，不发送消息。全局或群开关变化使对应待确认操作失效。已经提交平台的发送无法撤回。

配置和持久数据纳入私有迁移包，校验机器人账号与群范围，配置冲突目标优先、补齐缺项。定时发送进度保守合并，已结束状态和较晚的执行位置不因旧副本倒退。内置插件代码由项目部署；生成插件的版本快照随私有迁移包迁移，调用前核验内容哈希。定时待确认提议仅存内存，不迁移，重启后须重新提出；开发申请及任务持久保存。

## 使用说明

在群内使用时先@机器人：

| 指令 | 权限与作用 |
| --- | --- |
| `/插件` | 查看当前可见插件状态；机器人主人可查看本账号已安装插件 |
| `/插件 本群 schedule 关闭` | 群管理员以上停用本群定时消息 |
| `/插件 本群 schedule 开启` | 群管理员以上启用本群定时消息，仍受全局开关限制 |
| `/插件 全局 schedule 关闭` | 仅机器人主人关闭本账号定时插件 |
| `/插件 全局 schedule 开启` | 仅机器人主人开启本账号定时插件，不改变各群选择 |

当前本机定时插件已绑定指定群并开启，全局及本群开关均开启，初始无任务。绑定保存在被Git忽略的 `data/plugins.json`，换机须使用私有迁移包；单独复制代码不会自动绑定任何群。

验证时在目标群查看插件，在其他群尝试启用应被拒绝；普通成员修改开关应被拒绝；全局关闭后本群开启不能恢复运行。插件异常可查看 `logs/model/` 内的 `plugin_error`、`plugin_config_error` 和工具调用事件。定时功能具体操作见 [定时消息](SCHEDULE.md)。

### 后台管理

本机后台“设置”提供全局开关和批量卸载，“群管理”只控制当前群的插件开关。开关即时生效，旧快照不能覆盖新的开关；定时扩展关闭再开启后旧确认失效，不补发停用期间的计划。卸载前停止机器人，配置、任务与运行数据从活动目录移除并备份，核心功能不能卸载。生成插件的历史开发任务及报告保留，随仓库提供的定时扩展源码不删除。配置与并发细节见 [后台设置](SETTINGS.md)。

聊天回复阶段可在未 @ 的连续对话中识别明确任务或插件委托并调用工具，参与判断仅决定是否回复及提供指代参考。工具始终绑定当前真实发起人和会话，沿用原有身份权限与审批；普通闲聊、引用或旧任务不构成新操作授权。模型提示 `llm.action_intent.0` 管理此意图边界。
