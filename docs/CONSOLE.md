# 可视化后台

## 设计

后台供本机维护者查看机器人记忆的来源、修正个人与群认知、整理表情描述、维护提示词和迁移数据。仅本机浏览器可访问，无远程访问或多人账户功能。

所有内容可以手动编辑，点击保存直接写入并保留原值，无须查看差异；对话助手根据选中内容及必要参考资料提出完整修改建议，展示原值和新值后由维护者确认保存。生成建议本身不产生数据修改，也不代表事实已经核实。过期版本不得覆盖其他操作产生的新版本。

个人按机器人与 QQ 集中为一份档案，昵称不参与身份分组。每人只有一段跨会话总体认知，私聊保留一段会话印象，群内个人认知按角色、互动习惯、互动关系、补充认知四项分类。个人列表使用平台昵称，群子菜单使用平台群名；支持按群筛选已记录或平台目录中属于该群的人。总体认知集中使用，会话印象仅用于对应场景；后台确认的总体认知、私聊段落或群内分类独立固定保留，空值也固定，自动提取不能覆盖；其他分类继续更新。自动总体认知逐条检查来源公开审核，未经审核不跨来源会话使用。群摘要与群认知按机器人及群隔离，由维护者手动维护或生成建议后确认。群认知提供背景，不授予权限。

表情说明以图片内容关联，同图副本共享认知。提示词可以编辑总体规则、人设、风格、处理阶段说明和工具描述；工具参数结构、程序权限检查及实际能力仍由程序控制，修改说明不会创造新工具。

人格和风格可新增、删除，同名资源不能覆盖。默认模板和仍被群选择的模板不能删除，需先切换群设定。系统规则及处理阶段提示词不支持新增和删除。表情包支持上传 PNG、JPEG、GIF、WebP，按当前图片大小配置限制；删除仅移除所选图片，同图共享认知保留。新增和删除由维护者手动确认，不交给模型执行。

后台独立于机器人，机器人停止后仍可备份和导入。导入沿用同号合并、异号拒绝和导入前备份规则，不改变 QQ 或 NapCat 登录态。

## 开发

### 结构与数据

- `console_endpoint.py`：统一定义 Python 服务监听地址与机器人回复的后台地址；`/后台` 仅机器人所有者可用，明确的自然语言入口询问映射到同一指令，结果原样发送。
- `admin_server.py`：FastAPI 接口，仅监听 `127.0.0.1:8090`。复用现有依赖，无前端构建工具或第三方 CDN。
- `admin/index.html`、`admin/style.css`、`admin/app.js`：原生浏览器界面，支持窄屏布局、草稿编辑、差异弹窗和对话建议。
- `console_store.py`：受限资源读写、数据校验、内容版本检查和修改记录。个人、消息修改在 SQLite 写事务中检查版本；文件配置使用同目录临时文件替换。
- `prompts/catalog.json`：随代码管理的默认提示词目录；`plugins/assistant/prompt_store.py` 读取实时覆盖并替换声明的日期、账号及会话占位符。占位符不能删除。
- `data/console.json`：本机提示词覆盖和以 `机器人QQ:群号` 为键的群摘要、群认知。被 Git 忽略并纳入 ZIP 迁移。迁移时同名配置目标优先、来源缺项补齐，账号不一致拒绝。
- 人格、风格沿用 `personas/`、`styles/`；群参与配置沿用 `group_chat.json`；个人认知和消息沿用 `data/memory.sqlite3`；表情描述沿用图库 `.memory.sqlite3`。
- `backups/admin-edits/`：每次后台修改的原值、新值、时间、资源和完成状态，不记录模型密钥。默认不随迁移包导出，可在原机器查看最近 100 条记录。

资源生命周期接口为 `/api/profiles`、`/api/emotes/upload` 和 `/api/resource/delete`，统一沿用本机访问、会话令牌和迁移互斥检查。上传使用原始文件流并检查文件签名、扩展名及字节上限；文件名称检查拒绝路径、链接和 Windows 特殊名称。删除检查资源版本和群引用，原文件写入操作记录旁的 `.bin` 备份，再删除图库或模板文件。`GroupSettings.set_profile` 与删除共用迁移锁，锁内检查模板存在，防止同时切换到已删除的模板。

操作记录中可撤销新增和删除：撤销新增按当前版本执行删除，正在使用的模板仍受保护；撤销删除校验备份并恢复完整文件，遇到同名文件拒绝覆盖。表情描述保留在原图库数据库中，恢复图片时使用当前共享认知。

### 生效与并发

正式回复及群参与判断读取该群认知；后台维护的个人认知以“后台维护者修正”标记固定。清空字段也保留固定空值，避免自动提取恢复旧认知。现有 QQ 管理指令可以重新设置或忘记字段，取消对应固定标记。

短期会话在有数据库时每次从持久记录读取，使历史更正及时生效。消息更正同时更新可关联的完整问答，删除引用该消息的旧认知并把旧公开审核标为不公开；不改变原消息 ID 和时间。旧消息不重新作为发送请求执行。撤销消息更正会恢复正文和关联问答，不自动恢复已经失效的认知或公开审核。

提示词覆盖、人格、风格及群认知对后续请求生效，在途请求不重新生成。通知改写缓存包含提示词覆盖版本。工具说明发送前刷新，工具参数结构不允许后台编辑。

维护操作与迁移共用排他锁，机器人运行与导入沿用运行锁。网页导入上传上限为 512 MiB；更大文件用命令行。导出保留服务器端 ZIP 并下载浏览器副本。

### 模型建议与预览

后台复用 `.env` 选择的模型和凭据，建议请求禁用工具调用，输出仅接受当前资源相同结构的完整值及说明。总体认知请求附该人各会话的发言及关联回复，会话印象请求仅附当前会话资料，群请求只附该群记录；每个会话最多 120 条，总预算约 180 条，均衡抽取全时间段与近期记录，每条最多 600 字，并附抽样数量、来源会话、消息 ID、昵称、引用及角色元数据。资料不足不推断；表情请求附当前图片，需当前模型支持图片输入；提示词请求发送选中提示词及维护者对话。不会发送 `.env` 密钥。对话最多 16 条、每条最多 30000 字；建议输出额度至少为 8192 token。模型输出格式不合法时最多请求一次格式修正，仍不合法、模型失败或版本冲突均不保存。

“完整请求组装预览”走正式回复组装逻辑，在发送 API 前截获消息和工具列表，不实际调用模型。预览包含当前保存的提示词、身份结构、个人及群认知、已有问答、测试消息及工具说明。平台角色未实时查询，图片、工具结果、在线话题状态及共同群发送权限不在离线预览中；它不代表过去某次请求的抓包。

### 本机访问边界

服务绑定回环地址，核验 Host、Origin 和跨站请求来源。写请求携带当前后台实例的随机令牌，不启用跨域访问；重启后台后旧页面需刷新。页面使用本地静态资源、内容安全策略和文本转义。任何可使用本机账户的程序都可能访问后台，因此这里不提供操作系统用户之间的权限隔离。

## 使用说明

后台采用左侧固定菜单、右侧功能内容布局，窄窗口保持相同结构。页面直接显示功能控件，不重复展示页面标题和用途介绍。顶部以资源路径显示当前选择，包含个人与当前总体认知、私聊或群；编辑面板不重复显示姓名和 QQ 标题，分类字段仅显示类别名称。

1. 双击根目录 `start.bat` 同时启动后台、NapCat 和机器人，或执行 `.\.venv\Scripts\python.exe admin_server.py`，访问 `http://127.0.0.1:8090`。
2. 手动修改直接点击“保存”，模型建议点击“查看建议差异”并确认后才保存；不提供单独的重新载入按钮。选择“个人认知”，用“按群筛选个人”下拉框筛选，也可输入昵称或 QQ 搜索。点击个人昵称直接显示总体认知，并展开私聊及各群子菜单；右侧显示总体认知、私聊印象或所选群的四项分类，总体认知不另设子菜单。
3. 点击“根据聊天重新整理”生成当前总体认知或会话的建议，查看差异后确认；不会修改其他会话印象。群内原有四项分类直接保留；已合并的段落及其他旧内容完整放入补充认知，不自动推断分类。原文与依据保留，只有实际修改的段落或分类被替换并固定。批量整理建议可同时涉及总体和各会话，确认弹窗展示所有改动。

4. 在“提示词管理”选择总体规则、人设、风格或阶段说明。占位符保持原样。“载入默认值”只改变草稿，点击“保存”后生效。
   - 点击“新增人格 / 风格”，填写类型、名称和正文并确认。新增后到群设定中选择，或在对应群通过人格、风格指令切换；无需重启机器人。
   - 选择人格或风格后点击“删除”；默认模板不显示删除按钮。若提示被群使用，先在对应群切换后重试。
   - 在“表情包管理”点击“上传表情包”，选择图片、核对预览及文件名后确认。大小限制由 `.env` 的 `EMOTES_MAX_BYTES` 决定，默认 5 MiB。上传后可维护表情说明；选择图片后可删除。
   - 新增或删除有误时，在“操作记录”找到对应条目并撤销。删除备份只保留在本机，不包含在私有迁移包中。
5. “聊天记录管理”按会话、发送者、关键词检索，每页 50 条；更正原文会使相关旧认知依据失效，请优先通过认知编辑处理理解偏差。
6. “操作记录”查看前后内容；只有当前内容仍对应该修改结果时才能撤销，防止覆盖之后的操作。未完成保存的记录需人工核对。
7. “数据迁移”可以生成并下载普通 ZIP。导入前停止机器人，选中 ZIP 并输入目标 QQ（新部署必填），确认后同号合并。后台无需停止。

初次升级需重新启动机器人以加载维护支持；之后后台保存无需重启机器人。统一启动脚本会重启本项目后台与机器人以加载当前代码；只结束本项目入口对应的进程，其他项目进程不受影响。

### 验证和排查

- 保存后重新选择相同资源，核对保存值；使用请求组装预览检查总体提示词、群认知和个人认知。
- 模型建议显示失败：确认 `.env` 选中的服务商、模型及密钥有效；图片建议需要视觉能力。已保存内容不受失败影响。
- 内容已变化：重新选择资源读取最新版本，再应用当前需求，不反复提交旧版本。
- 无聊天数据库：先运行机器人接收消息或从迁移包导入。
- 导入被拒绝：先停止机器人，并核对机器人账号；未完成导入使用 `migration.py recover`。
- 后台无法启动：检查 8090 端口；直接执行 `admin_server.py` 可查看启动错误。

自动测试使用隔离数据和模拟模型，覆盖本机请求边界、确认前不写入、提示词实时生效、固定认知、群隔离、版本冲突、历史更正、无网络预览、迁移包含新增配置。浏览器验证覆盖导航、提示词编辑、差异弹窗和表情图片展示。

### 批量重新整理

执行 `.\.venv\Scripts\python.exe scripts/rebuild_knowledge.py`，使用当前模型配置为全部个人与群生成待确认建议；有效旧建议直接复用，失败可以重跑。输出仅含进度与状态，不显示聊天正文或密钥。建议存放在 Git 忽略的 `backups/knowledge-proposals/`，不属于已保存认知，也不随迁移包导出。

重新启动后台后打开对应个人或群，已有建议自动载入，点击“查看建议差异”再“确认并保存”。生成和确认前均检查资源版本；生成时已有的聊天依据被更正、删除，或新增会话、认知变动时，旧建议失效；已有会话的新消息不作废历史建议。保存时操作记录保留旧值与模型依据说明。

总体认知使用 `facts.grp=0`；会话继续使用实际群号或负的本人 QQ，字段由 `plugins/assistant/knowledge.py` 统一定义。迁移沿用事实表和来源 ID 映射，无新增数据库文件。自动片段使用会话与依据文本的稳定哈希区分，迁移映射来源消息 ID 时不改变片段身份；运行时先按每条依据核验，再合并为总体认知或当前会话印象。按群清空只删除该群会话认知及来源于被删除消息的自动总体认知；手动确认的总体资料继续保留，可用本人 `/忘记` 删除对应字段，或通过全部清空删除。后台与机器人代码更新后均需重新启动进程。


### 平台昵称与群名

`contacts.py` 在机器人连接时立即同步群列表、群成员昵称与好友昵称，并为历史记录中未被名单覆盖的人查询平台昵称；成功后每五分钟刷新，查询失败则下次三十秒轮询重试；收到消息时更新该发送者的平台昵称，不以群名片或模型总结代替昵称。结果写入 Git 忽略的 `data/contacts.json`，独立后台读取此缓存。该文件只是可重建的显示目录，不提供权限，也不纳入私有迁移包；历史消息额外保留 `sender_nickname` 供离线回退。

更新代码后运行 `start.bat`，统一入口重启本项目后台和机器人以加载当前代码；QQ 登录连接后点击后台“刷新数据”。机器人离线或平台查询失败时保留最近同步结果；从未同步的昵称只回退到历史明确记录的平台昵称，不采用旧群名片或认知称呼；仍缺失时显示“昵称待同步”，群名缺失显示“群名待同步（群号）”，不猜测群名。按群筛选兼顾已有会话与最近获取的成员名单，因此离群者的已存历史仍可按原群查看。

### 机器人运行状态

页面最上方的运行状态与“刷新数据”按钮同排居中对齐，当前选中资源另起一行显示；运行状态与本次运行时长每五秒更新。机器人启动但消息接入未连接时显示等待连接；连接中显示已连接；正常退出显示已停止。二十秒未收到心跳则显示心跳中断，不将旧缓存误认为在线。后台连接失败单独提示状态读取失败。

左上角使用登录接口返回的机器人昵称和 QQ 头像；离线时保留最后识别的账号资料，头像加载失败显示占位图标。头像由后台从固定的 QQ 头像服务读取并短时缓存，浏览器只访问本机接口，头像失败不影响管理操作。运行心跳由 `plugins/assistant/runtime.py` 写入 `data/runtime.json`，后台 `/api/runtime` 只返回状态、运行时间与公开显示资料；此临时文件不参与私有迁移。机器人和后台更新后需要重启，页面刷新后展示状态。
