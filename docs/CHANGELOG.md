# 变更记录

按最后一次相关改动的日期倒序记录重要变化；同一主题的连续调整合并为最终效果。历史条目反映该阶段的变化，当前行为以模块文档为准。

## 2026-10-29

### 统一记忆与后台管理

- 统一记忆（含 10 月 28 日重构）：同一机器人账号的群聊与私聊共享记忆、人物认知和全局人设，不同机器人账号隔离；保留来源、修改历史、人工固定及权重衰减。记忆正文使用 Markdown，事实整理通过持久队列执行，Basic Memory 提供文本索引；召回兼顾近期跨会话片段，来源被删除或修改后相关自动记忆失效。旧认知支持离线升级、备份和冲突隔离。
- 后台记忆库按人物、主题和事件组织阅读，提供来源、历史、召回测试、记忆活动和整理状态；活动展示前后变化，列表分页并按需加载。机器人档案、兴趣及每日记录统一管理，表情描述和个人反馈纳入统一记忆，保留真实来源与人工修正。

### Obsidian 接入

- Obsidian 接入同一记忆库，提供导航、图谱及编辑工作台。首次需在客户端登记仓库；编辑稿由后台审阅差异并确认后写入，版本冲突保留草稿，稿件及审阅基线随私有数据迁移。

### 后台模块结构

- 后台支持模块归入 `admin/`，启动入口保持不变。

## 2026-10-28

### DSH 运行能力检查

- DSH 接入按实际运行能力检查，不再绑定客户端或随附运行时版本；缺少能力时提供具体诊断。

### 话题判断

- 话题判断统一使用平台消息编号并逐条校验；错误判断单独重试，仍无法确认时留存并旁听，不阻塞后续消息。

### 联合启动排查

- 联合启动说明补充 Windows 下载来源安全提示及桌面快捷方式的排查方法。

## 2026-10-27

### 聊天图片存储

- 聊天图片存入独立执行会话，客户端浏览图片通过队列补写；补写失败保留待处理记录，不影响聊天回复。

## 2026-10-26

### Git 自更新

- 所有者可通过自然语言请求 Git 自更新，工具执行时校验权限；机器人退出后由独立监护检查并快进更新、安装依赖、重启后台及机器人。脏工作区、分叉、无上游或迁移冲突会阻止更新。

### DSH 浏览会话

- DSH 浏览会话被客户端占用时保留补写队列并退避重试，释放后自动恢复，减少重复警告。

### 启动与配置迁移

- 修复配置迁移时插件加载顺序和锁使用导致的启动失败。

### 能力模块与历史查询

- 提示词和工具定义整合为能力模块，后台支持整模块编辑与契约查看；历史查询拆分为独立工具，旧覆盖和私有包按新结构迁移。

### 群话题参与策略

- 群话题参与人数支持全局默认和单群覆盖，默认两人；选择“10+”关闭主动回复，直接呼叫仍可回应。达到门槛后持续评估，并保留已发言话题的续话规则。

## 2026-10-22

### 群话题策略与日志

- 群话题使用参与门槛及针对机器人发言的续话规则；后台话题日志保存完整话题消息和回复依据，仅展示已成功回复的话题。

## 2026-10-20

### 聊天图片与历史

- 聊天图片独立留档并纳入私有迁移，历史查询可按权限读取原图；连续会话增量补充背景和消息变化。

### 主 Agent 与表情

- 主 Agent 获得更完整的聊天、工具与表情处理能力；表情支持按群记录使用经验和停用，人工修正保留版本保护。

### DSH 预算与错误提示

- DSH 预算耗尽时停止新工具并允许一次受时限约束的收尾；错误提示区分预算、超时和图片能力问题。

## 2026-10-19

- 客户端浏览会话支持重建和待同步消息恢复；图片请求校验模型视觉能力。

### 后台会话

- 后台支持重置全部 Agent 会话而保留聊天、记忆、人设及任务。

### 人设试聊

- 人设编辑支持规则检查和虚构场景试聊。
