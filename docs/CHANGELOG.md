# 版本变化

## 2026-10-09

- 修复统一启动复用旧后台导致资料显示未更新的问题；连接后立即发布群名、补查历史用户昵称，失败及时重试，不再将旧群名片用作当前昵称。

- 个人记忆管理改为个人认知，使用平台昵称、群名、个人会话子菜单及按群筛选。
- 个人资料改为一段总体认知和每会话一段印象，旧分类文字保留；按段落编辑和生成建议，保留来源隔离与跨会话公开审核。

- 个人记忆按机器人与 QQ 集中，分为总体资料及私聊/各群的角色、关系和习惯；统一昵称显示。
- 支持从跨会话聊天重新整理个人认知、从本群聊天重新整理群认知，批量生成待确认建议，保留来源说明与版本检查。
- 确认后原子替换重复旧认知；会话认知隔离，自动总体资料沿用来源公开审核，固定修正不可被自动覆盖。

- 后台支持人格、风格新增删除及表情包上传删除，保留默认模板和已被群使用的模板。
- 新增删除原文件备份、操作记录撤销、同名与版本冲突保护；群提示词切换与后台删除互斥。

- 合并启动批处理，`start.bat` 统一启动后台、NapCat 和机器人，移除独立后台启动脚本；后台保持独立进程。
- 新增仅机器人所有者可用的 `/后台` 及常见自然语言入口查询，返回固定本机地址与访问限制。

## 2026-10-08

- 新增仅本机可访问的可视化后台，支持个人、群、聊天档案、表情认知和提示词编辑。
- 后台使用管理类菜单名称，菜单固定在左侧，右侧直接显示功能内容，移除重复页面标题和用途介绍。
- 新增对话修改建议、前后差异确认、版本冲突检查和修改记录撤销。
- 新增持久化群摘要与群认知，并接入群聊回复和参与判断。
- 提示词集中管理并实时加载覆盖，迁移包包含群认知和提示词覆盖。

## 2026-10-07

- 新增本地私有数据 ZIP 导出和导入，包含记忆、表情包、人设、群配置及密钥配置。
- 同号合并、异号拒绝，支持来源引用重映射、重复导入去重及配置冲突保留。
- 新增导入前备份、异常回滚、崩溃恢复和机器人运行互斥锁。
