# 变更记录

按日期倒序记录有影响的功能与版本变化。

## 2026-10-12

- 持久问答按会话有效期恢复并保留时间，过期记录仍可查询。
- 已结束且已通知任务退出默认上下文，任务只注入一次简短状态，避免重复夹带旧源码与报告。
- 统一项目变更记录至 docs/CHANGELOG.md，合并同日条目并按日期倒序排列；校正项目说明及模块文档结构。

## 2026-10-10

- 修复模型一次返回多个工具调用时直接向用户提示“请模型每轮只调用一个工具”并终止回复的问题。
- 多调用按步骤恢复：执行首个，其余明确回传未执行状态，模型读取结果后按需继续；保留调用预算、权限、图片记忆及发送去重规则。
- 增加整批调用编号校验、未执行诊断记录及两家服务商协议和副作用边界测试。
- 旧问答改为明确标记的历史背景，当前群聊紧邻本次问题，并传递本次问题指向，降低话题切换后误接旧任务的风险。
- 命令实际发送结果保存为持久问答，后续可获知确认、完成或拒绝状态，发送失败不误记成功。
- 新增损友、小鲸鱼、猫娘、技术宅四组可独立选择的人格与说话方式模板，沿用现有工具及权限机制；补充搭配、切换和验证说明。
- 新增可信本地插件体系，支持按机器人全局和群独立开关、群范围绑定及私有数据迁移。
- 新增群定时消息插件，支持管理员自然语言提议、确认码创建或取消、北京时间单次及每天计划；错过不补发，发送结果不明不重试。
- 新增默认开启、可关闭的本机模型诊断日志，记录动态上下文、工具执行、模型用量、参与判断及消息发送结果，以独立编号关联调用链路。
- 固定提示词保存标识与摘要，过滤凭据及内部推理；诊断日志按天和大小轮转，默认保留 7 天。
- 修正后台开发任务路由：参与判断不再判断能力，回复阶段依据任务工具申请执行，试玩链接交付条件由执行器核实。
- 精简任务创建与完成通知，取消重复排队和启动播报；默认仅发送实际结果，执行与验收细节保留供追问。
- 接入本机 DeepSeek Harness，支持自然语言申请任务、主人私聊审批、免重复审批补充、查询及取消。
- 所有群共享任务执行队列，默认最多两个任务；机器人上下文包含实时任务状态，执行事件可追溯。
- 生成插件通过独立进程测试后自动发布到原群，沿用全局及群开关；任务台账和产物纳入私有迁移。

## 2026-10-09

- 后台顶部新增机器人连接状态、心跳中断提示与运行时长，与刷新数据按钮同排对齐；左上角显示机器人平台头像和昵称。
- 后台以顶部资源路径标识当前选择，移除编辑面板重复标题和分类群名前缀；手动编辑直接保存，模型建议继续经差异确认保存，取消重新载入按钮。
- 个人的各群认知保留角色、互动习惯、互动关系、补充认知四类，支持分别编辑与固定；总体认知和私聊印象仍为段落，已有未分类内容完整保留在补充认知中。
- 修复 Windows PowerShell 5.1 中文响应解码导致后台已运行却误报未启动的问题，启动探测改用固定 ASCII 服务标识。
- 修复统一启动复用旧后台导致资料显示未更新的问题；连接后立即发布群名、补查历史用户昵称，失败及时重试，不再将旧群名片用作当前昵称。
- 个人记忆管理改为个人认知，使用平台昵称、群名、个人会话子菜单及按群筛选。
- 个人资料改为一段总体认知和每会话一段印象，旧分类文字保留；按段落编辑和生成建议，保留来源隔离与跨会话公开审核。
- 个人记忆按机器人与 QQ 集中，分为总体资料及私聊/各群的角色、关系和习惯；统一昵称显示。
- 支持从跨会话聊天重新整理个人认知、从本群聊天重新整理群认知，批量生成待确认建议，保留来源说明与版本检查。
- 确认后原子替换重复旧认知；会话认知隔离，自动总体资料沿用来源公开审核，固定修正不可被自动覆盖。
- 后台支持人格、风格新增删除及表情包上传删除，保留默认模板和已被群使用的模板。
- 新增删除原文件备份、操作记录撤销、同名与版本冲突保护；群提示词切换与后台删除互斥。
- 合并启动批处理，`start.bat` 统一启动后台、NapCat 和机器人，移除独立后台启动脚本；后台保持独立进程。
- 新增仅机器人所有者可用的 `/后台` 及常见自然语言入口查询，返回固定本机地址与访问限制。
- 联网回复根据搜索结果直接解释，不再附带参考链接、来源列表或引用编号；总结失败时明确提示重试。

## 2026-10-08

- 新增仅本机可访问的可视化后台，支持个人、群、聊天档案、表情认知和提示词编辑。
- 后台使用管理类菜单名称，菜单固定在左侧，右侧直接显示功能内容，移除重复页面标题和用途介绍。
- 新增对话修改建议、前后差异确认、版本冲突检查和修改记录撤销。
- 新增持久化群摘要与群认知，并接入群聊回复和参与判断。
- 提示词集中管理并实时加载覆盖，迁移包包含群认知和提示词覆盖。
- Windows 启动入口支持自动拉起 NapCat，首次配置启动文件路径，统一保存到 `.env`，后续复用。
- 增加本机监听端口配置、启动前校验与启动等待，保留扫码窗口和现有机器人重启行为。

## 2026-10-07

- 新增本地私有数据 ZIP 导出和导入，包含记忆、表情包、人设、群配置及密钥配置。
- 同号合并、异号拒绝，支持来源引用重映射、重复导入去重及配置冲突保留。
- 新增导入前备份、异常回滚、崩溃恢复和机器人运行互斥锁。
