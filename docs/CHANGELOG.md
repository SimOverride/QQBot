# 变更记录

## 2026-10-29：整理后台模块目录

- 后台支持模块归入 `admin/`，同步更新代码引用和相关开发文档；后台启动入口保持不变。

## 2026-10-28 统一记忆重构

- 同一机器人全部群聊、私聊共享记忆和全局人设，保留人物身份及来源。
- Markdown 记忆库、独立 Basic Memory 文本索引、持久化事实整理队列、修正历史与权重衰减。
- 后台增加统一记忆、机器人档案和运行状态；保留人工固定与差异确认。
- 提供旧认知离线升级、冲突隔离及笔记和任务队列的迁移。升级前先预演和备份。

## 2026-10-28：DSH 按运行能力接入

- 取消具体客户端和随附运行时版本号限制，改为检查安装入口及聊天、任务、会话、图片桥接所需模块接口；安装更新后重新探测，不按版本字符串拒绝兼容客户端。
- 缺少运行能力或安装不可用时提供具体受控诊断，不再退化成通用处理失败提示；能力检查不调用模型或传递密钥。

## 2026-10-28：补充 Windows 启动安全提示排查

- 联合启动说明增加指定入口解除下载来源标记及项目专用桌面快捷方式的配置，处理本地路径被安全区域判为 Internet 时的反复提示。

## 2026-10-28：修复回应机器人时话题校验阻止回复

- 话题观察模型统一使用 QQ 消息编号，移除内部归档编号，明确回应依据的发送者、话题及时间约束。
- 消息逐条校验与提交，无效项单独重判一次，仍失败则完整留存并保持旁听；旧错误不再阻塞后续合法消息或卡住处理游标。
- 重判按旧消息当时的上下文执行，禁止引用未来话题与机器人发言；诊断日志增加明确的校验类别、重判和留存结果。

## 2026-10-27：聊天图片执行存储与客户端分离

- 聊天图片附件改存各自执行会话目录，避免原生附件服务对客户端根目录执行 `chmod` 被拒绝后中断聊天；已有会话的旧图片按实际引用核验并迁入。
- 客户端浏览图片改为随会话队列独立补写，保持原生图片引用，原子发布并校验已有对象；补写失败保留队列，不影响聊天回答。

## 2026-10-26：自更新改为自然语言工具调用

- 移除更新话语的正则门槛，所有者会话始终提供更新工具，由模型理解当前要求并决定调用。
- 保留执行时的所有者权限校验、仓库检查和停机更新流程。

## 2026-10-26：所有者触发 Git 自更新

- 新增所有者明确要求时可调用的更新工具，当前回合绑定授权，成功回复后通知停机。
- 联合启动增加独立监护，机器人退出后检查当前分支上游并仅快进更新，安装依赖、重启后台及机器人，保留 NapCat。
- 拒绝脏工作区、分叉和无上游；迁移互斥，失败记录阶段并停止，不自动回滚或重试。

## 2026-10-26：修复 DSH 浏览会话占用时警告刷屏

- 客户端持有浏览会话写锁时归类为正常等待，队列保留并自动补写；占用和恢复仅提示一次，同类真实错误不重复报警。
- 后台补写持续受阻时逐步退避至最多 5 分钟，恢复后回到 15 秒；诊断日志记录每次检查摘要，避免输出原生异常正文。
- 使用客户端原生运行时验证持锁等待、释放后补写、重复重试去重及真实无效事件报错。

## 2026-10-26：修复插件提前导入导致启动失败

- 配置迁移入口延后至 NoneBot 正式加载插件之后导入，迁移完成后再注册插件运行逻辑。
- 新增独立进程启动回归，覆盖真实插件加载、配置迁移和初始化注册，测试不启动网络服务。

## 2026-10-26：修复配置迁移阻止机器人启动

- 配置迁移明确获取迁移锁，避免重复申请机器人已持有的运行锁；锁选项改为仅接受命名参数。
- 补充持有运行锁时迁移旧配置、校验新配置及迁移互斥的回归测试。

## 2026-10-26：能力模块与历史查询重构

- 提示词和29个工具定义统一到8个完整能力模块；后台整模块编辑、查看注入位置与工具契约，保留人设独立编辑。
- 历史读取拆为会话列表、消息搜索、前后文、人物或群查找、认知读取五个工具，搜索默认当前会话，跨会话权限保持隔离。
- 本机旧覆盖启动时备份迁移，旧私有包导入按新模块字段合并；删除旧碎片目录、通用历史动作入口和按说明原文替换实现。

## 2026-10-26：后台调整话题参与人数

- 设置页新增默认接话参与人数滑块，群管理支持独立人数及恢复跟随默认，默认2人，范围1～9人和“10+”，保存后后续消息生效。“10+”关闭主动回复，直接 @仍回应；生成期间关闭会停止尚未发出的主动回复。
- 达到人数门槛后，每批新消息均持续评估，不要求新增成员，不限制评估次数；模型获得完整参与者人数依据，人数越多越倾向接话。
- 已发言话题仍仅回应针对机器人说法的讨论；人数配置沿用版本检查、原值备份及私有迁移。

## 2026-10-22：固定话题参与策略与后台话题日志

- 移除积极性指令、默认和群滑块；新话题至少两位群成员参与才考虑接话，第三人加入可再次评估，直接呼叫沿用即时回应。
- 机器人发言后，仅在群友回应或讨论其具体说法时考虑续话；全体提醒遵循普通话题策略。
- 持久记录话题起始消息、完整已识别聊天、话题判断、回复原因及实际发送结果，重启保留参与状态。
- 后台新增话题日志，仅显示有成功回复的话题，提供群筛选、标题搜索和聊天气泡分页查看。
