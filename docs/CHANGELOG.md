# 变更记录


按日期倒序记录有影响的功能与版本变化。

## 2026-10-19

- 主 DSH agent 统一参与、静默、引用、复读与工具执行；取消独立参与评分及积极性二次阈值。
- 工具注册表支持多调用、并行读取及顺序写入；采用共享时间、Token、调用次数与可选费用预算，图片描述不再是强制后续步骤。
- 原生执行会话按群/私聊持续恢复；权限范围变化或清除历史时切换上下文。模块事件自动进入主会话，任务结果由主 agent 判断通知，发送失败与过期状态保留。

- DSH 会话标题按“群名（群号）”或“昵称（QQ号）”显示，名称使用平台联系人信息，内部会话仍按机器人账号隔离。

- DSH 客户端可按机器人账号及群/私聊查看连续聊天记录，正常完成回合追加原生模型与工具事件；浏览历史与机器人模型上下文隔离，后台试聊不写入。

- 聊天与任务使用 DeepSeek Harness 客户端 0.2.1-rc.2 随附运行时；聊天由 DSH 驱动模型及原生工具回合，保留会话隔离、业务权限、发送去重与任务审批。
- 新增当前会话能力查询和按权限启停插件，动态刷新可用工具；增加自然措辞指引与普通聊天语义分条，发送停顿保持不变。
- 后台人设编辑支持规则检查及固定虚构场景的保存版本/草稿对比试聊，试聊不发 QQ、不写记忆、不执行工具或保存草稿。

## 2026-10-16

- 原生“@全体成员”优先进入群参与判断，缩短判断间隔并临时提高关注值；积极性为零时也允许判断，仍由模型决定是否回应，保持权限及过期发送保护。

## 2026-10-15

- 群聊支持自然跟随多人纯文字复读，由模型决定参与，直接发送原文且不添加其他内容；同文三十分钟内不重复跟读，继续遵守积极性和过时回复保护。

- 将被拍后的具体反应、主动拍人及收住互动的偏好写入五份内置人设；公共拍一拍提示词和工具说明仅保留调用方法、通知字段、结果状态和程序限制。

## 2026-10-14

- 新增群聊和获准私聊的被拍通知处理，由模型按人设决定回应、拍回去或静默；支持拍当前群成员及当前私聊对象，限制重复发送并记录结果，通知不作为用户自述或 QQ 引用目标。

## 2026-10-13

- 取消未 @ 回复阶段的任务与插件工具屏蔽，由聊天模型识别明确委托，工具继续核验真实身份、会话范围及审批。

- 修复个人认知提取截断或格式失败后每分钟重复请求的问题；使用独立 JSON 输出及额度，关闭提取阶段深度思考，严格校验完整结果。
- 同批最多三次请求，失败按五分钟、三十分钟退避后暂停；预算持久化并随同版本迁移保留，不因新增消息或重启重置，不阻塞其他人的提取；保留原文、游标及人工恢复入口。

- 支持读取 B 站视频、网易云歌曲/专辑/歌单的标题、作者及公开介绍，以及小黑盒公开帖子正文；支持链接、分享卡片、引用、连续消息与合并转发，失败明确说明，不将简介冒充音视频内容。

- 修复本机代理 Fake-IP 导致搜索图片无法核验：重新解析并固定公网目标，继续阻止内网访问；下载失败返回具体原因，不占用安全审核额度，下载尝试仍有上限。
- 表情收藏优先考虑同群十分钟内多人复读及人设相关图片；安全审核与收藏偏好分离。支持安全检查后直接发送搜索图片，无须收藏，关闭自动收藏仍可使用。

- 表情检索增加关键词组合、情绪同义词、会话使用记录和防重复排序；新增原图复查及后台确认描述修正，各人设补充使用时机偏好。
- 群内直接呼叫合并同一人的连续补充，支持自然分条、过期回复停止及指定上下文消息引用；修正引用图片来源编号。
- 新增受限的合并转发读取；认知整理保留变化前值及来源，继续保护人工固定内容。

## 2026-10-12

- 名称仅保留文字颜色，取消背景高亮；修复数字昵称拆分消息编号的问题。消息引用采用独立颜色，支持悬停查看单条、多条及编号范围的聊天气泡预览。

- 修正认知正文名称高亮被表单标题样式覆盖的问题，保持昵称、群名的颜色与行内排版；选中列表条目也保留名称高亮。

- 取消模型上下文自动附带昵称对应表；支持按昵称查询 QQ、按群名查询群号，查询范围沿用会话权限，同名返回候选。
- 个人与群认知统一替换历史编号格式，存储仍保留原始 ID；后台以不同颜色高亮人物昵称和群名。

- 认知按 QQ 存储，模型回复、参与判断和后台阅读统一按当前平台昵称呈现；保留工具数字账号，同名区分，未知昵称保留原号。
- 明确提供机器人自身 QQ、昵称和自身标记；后台阅读视图与原文编辑分离，昵称显示不会覆盖存储内容。

- 机器人启动时自动关闭当前 Windows 控制台快速编辑模式，避免鼠标选择导致心跳与收发暂停。

- 损友、猫娘、技术宅人设采用适配项目的角色卡，保留各自表达特征，统一实际工具、参与、授权和任务状态规则，去除虚构经历与不适用的强制发送要求。

- 小鲸鱼人设采用适配项目的群友版提示词，保留角色口吻，统一实际工具、参与规则、事实依据及任务通知边界。

- 人格与说话风格合并为单一人设，同名风格内容并入现有人格；统一后台选择、默认设置与 `/人设` 指令，移除独立风格资源和指令。人设上限为 12000 字，旧版双模板迁移包须在来源部署升级并合并后重新导出。

- 新增默认每日认知自动整理，按变化合并重复内容、保留待确认矛盾；保护人工固定内容与来源隔离，提供开关和间隔设置，后台及机器人共同读取整理结果。

- 支持纯文字 @机器人QQ号、昵称或本群名片触发聊天与命令，排除单独 @、邮箱及名称前缀误触发。

- 后台新增设置：运行参数、密钥替换、深度思考开关、默认积极性滑块与默认人格。
- 群管理提供积极性滑块和群插件开关；全局支持插件启停与停机批量卸载，增加并发版本保护及原文件备份。
- 移除聊天记录管理页面与原文编辑接口，保留认知与上下文所需历史数据。

- 持久问答按会话有效期恢复并保留时间，过期记录仍可查询。
- 已结束且已通知任务退出默认上下文，任务只注入一次简短状态，避免重复夹带旧源码与报告。
- 统一项目变更记录至 docs/CHANGELOG.md，合并同日条目并按日期倒序排列；校正项目说明及模块文档结构。

## 2026-10-10

- 修复模型一次返回多个工具调用时直接向用户提示“请模型每轮只调用一个工具”并终止回复的问题。
- 多调用按步骤恢复：执行首个，其余明确回传未执行状态，模型读取结果后按需继续；保留调用预算、权限、图片记忆及发送去重规则。
- 增加整批调用编号校验、未执行诊断记录及两家服务商协议和副作用边界测试。
- 旧问答改为明确标记的历史背景，当前群聊紧邻本次问题，并传递本次问题指向，降低话题切换后误接旧任务的风险。
- 命令实际发送结果保存为持久问答，后续可获知确认、完成或拒绝状态，发送失败不误记成功。
- 新增损友、小鲸鱼、猫娘、技术宅四组可独立选择的人格与说话方式模板，沿用现有工具及权限机制；补充搭配、切换和验证说明。
- 新增可信本地插件体系，支持按机器人全局和群独立开关、群范围绑定及私有数据迁移。
- 新增群定时消息插件，支持管理员自然语言提议、确认码创建或取消、北京时间单次及每天计划；错过不补发，发送结果不明不重试。
- 新增默认开启、可关闭的本机模型诊断日志，记录动态上下文、工具执行、模型用量、参与判断及消息发送结果，以独立编号关联调用链路。
- 固定提示词保存标识与摘要，过滤凭据及内部推理；诊断日志按天和大小轮转，默认保留 7 天。
- 修正后台开发任务路由：参与判断不再判断能力，回复阶段依据任务工具申请执行，试玩链接交付条件由执行器核实。
- 精简任务创建与完成通知，取消重复排队和启动播报；默认仅发送实际结果，执行与验收细节保留供追问。
- 接入本机 DeepSeek Harness，支持自然语言申请任务、主人私聊审批、免重复审批补充、查询及取消。
- 所有群共享任务执行队列，默认最多两个任务；机器人上下文包含实时任务状态，执行事件可追溯。
- 生成插件通过独立进程测试后自动发布到原群，沿用全局及群开关；任务台账和产物纳入私有迁移。

## 2026-10-09

- 后台顶部新增机器人连接状态、心跳中断提示与运行时长，与刷新数据按钮同排对齐；左上角显示机器人平台头像和昵称。
- 后台以顶部资源路径标识当前选择，移除编辑面板重复标题和分类群名前缀；手动编辑直接保存，模型建议继续经差异确认保存，取消重新载入按钮。
- 个人的各群认知保留角色、互动习惯、互动关系、补充认知四类，支持分别编辑与固定；总体认知和私聊印象仍为段落，已有未分类内容完整保留在补充认知中。
- 修复 Windows PowerShell 5.1 中文响应解码导致后台已运行却误报未启动的问题，启动探测改用固定 ASCII 服务标识。
- 修复统一启动复用旧后台导致资料显示未更新的问题；连接后立即发布群名、补查历史用户昵称，失败及时重试，不再将旧群名片用作当前昵称。
- 个人记忆管理改为个人认知，使用平台昵称、群名、个人会话子菜单及按群筛选。
- 个人资料改为一段总体认知和每会话一段印象，旧分类文字保留；按段落编辑和生成建议，保留来源隔离与跨会话公开审核。
- 个人记忆按机器人与 QQ 集中，分为总体资料及私聊/各群的角色、关系和习惯；统一昵称显示。
- 支持从跨会话聊天重新整理个人认知、从本群聊天重新整理群认知，批量生成待确认建议，保留来源说明与版本检查。
- 确认后原子替换重复旧认知；会话认知隔离，自动总体资料沿用来源公开审核，固定修正不可被自动覆盖。
- 后台支持人格、风格新增删除及表情包上传删除，保留默认模板和已被群使用的模板。
- 新增删除原文件备份、操作记录撤销、同名与版本冲突保护；群提示词切换与后台删除互斥。
- 合并启动批处理，`start.bat` 统一启动后台、NapCat 和机器人，移除独立后台启动脚本；后台保持独立进程。
- 新增仅机器人所有者可用的 `/后台` 及常见自然语言入口查询，返回固定本机地址与访问限制。
- 联网回复根据搜索结果直接解释，不再附带参考链接、来源列表或引用编号；总结失败时明确提示重试。

## 2026-10-08

- 新增仅本机可访问的可视化后台，支持个人、群、聊天档案、表情认知和提示词编辑。
- 后台使用管理类菜单名称，菜单固定在左侧，右侧直接显示功能内容，移除重复页面标题和用途介绍。
- 新增对话修改建议、前后差异确认、版本冲突检查和修改记录撤销。
- 新增持久化群摘要与群认知，并接入群聊回复和参与判断。
- 提示词集中管理并实时加载覆盖，迁移包包含群认知和提示词覆盖。
- Windows 启动入口支持自动拉起 NapCat，首次配置启动文件路径，统一保存到 `.env`，后续复用。
- 增加本机监听端口配置、启动前校验与启动等待，保留扫码窗口和现有机器人重启行为。

## 2026-10-07

- 新增本地私有数据 ZIP 导出和导入，包含记忆、表情包、人设、群配置及密钥配置。
- 同号合并、异号拒绝，支持来源引用重映射、重复导入去重及配置冲突保留。
- 新增导入前备份、异常回滚、崩溃恢复和机器人运行互斥锁。
