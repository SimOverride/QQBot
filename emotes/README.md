# 表情包文件夹

把 PNG、JPG、JPEG、GIF、WebP 图片直接放在此目录，每张默认不超过 5 MB。
支持静态表情和 GIF 动图，发送时保留原文件；不读取子文件夹。

请用能描述内容、情绪或用途的文件名，例如：

- 鲸鱼娘_无语_你认真的吗.png
- 蓝色大肥鱼_开心_收到.gif
- 鲸鱼娘_疑惑_问号.webp

机器人先检索候选，再直接查看原图，结合画面、文字、情绪和聊天语境选择。
文件名只是线索，不会代替看图；每页返回3张候选，可继续翻页。
首次查看的图片会发送给当前聊天模型理解，并保存画面、图中文字、情绪、适用场景等记忆。
记忆保存在本目录的 `.memory.sqlite3`；后续按描述检索和选择，不重复识图。
按图片内容校验关联，改名和同图副本可复用记忆，替换图片后重新识别。
内容记忆由模型生成，可能有误；需要全部重建时，停止机器人后删除 `.memory.sqlite3` 再启动。
新增、删除和重命名下次检索即生效，不需要重启。最多扫描1000个有效文件。
每次回复最多一张，可以只发表情，也可以配文字；没有合适的就不发。
已导入19张鲸鱼娘／蓝色大肥鱼精选表情并建立内容记忆；来源见 [SOURCES.md](SOURCES.md)。
也可以继续放入你想让机器人使用的表情包，新增图片由机器人首次查看时学习。

通过 .env 的 EMOTES_DIR 可以修改目录，默认是项目下的 emotes；
相对路径以项目根目录为基准。仅维护者在本地管理，不接受聊天指定任意文件发送。


机器人也可自主收藏本轮群聊图片，或在配置Tavily搜索密钥后联网找图。
新收藏文件以 `收藏_<SHA256>` 命名，内容描述自动保存为记忆，重复图片不再入库。
可通过 `.env` 设置 `EMOTES_AUTO_COLLECT=false` 关闭自动扩充，不影响现有表情发送。
